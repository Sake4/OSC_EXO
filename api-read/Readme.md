API Read/Update Node.js / Express

Gère la lecture et la modification sur les tables Groupe et Individu.


npm install

Lancer l'API


node server.js


L'API tourne sur https://api-node-prqv.onrender.com

Endpoints

 GET  /groupes  Liste tous les groupes 
 GET  /groupes/:id  Détail d'un groupe 
 PUT  /groupes/:id  Modifier un groupe 
 GET  /individus  Liste tous les individus 
 GET  /individus/:id  Détail d'un individu 
 PUT  /individus/:id  Modifier un individu
